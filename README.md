# wallpaper-theme — интерфейс под цвет обоев

Переключатель для Hyprland: панель, рамки окон, rofi, kitty, GTK-программы и
экран блокировки берут цвета из обоев — или остаются в теме Monochrome Vivid.

| Режим | Что происходит |
|---|---|
| `off` | ничего не подмешивается, всё как в теме |
| `vivid` | яркие цвета из обоев (matugen, схема vibrant) |
| `tinted` | чёрно-белое с лёгким оттенком обоев (matugen, схема neutral) |

Переключается в SUPER+R → Обои → «Интерфейс под обои» или командой
`wallpaper-theme mode vivid|tinted|off`. При смене обоев (руками, SUPER+W,
случайные при входе) цвета пересчитываются сами.

## Как устроено

Свои файлы темы не переписываются. `integrate` один раз добавляет в конец каждого
конфига подключение сгенерированного файла из `~/.local/state/wallpaper-theme/`; в
режиме `off` эти файлы пустые, поэтому выключение возвращает всё как было.

| Что | Как подключено | Когда видно |
|---|---|---|
| HyprPanel | её встроенный режим matugen (`theme.matugen` в config.json); свои цвета панели не трогаются | через ~5–10 с |
| Рамки окон | `source =` в hyprland.conf + `hyprctl keyword` | сразу |
| rofi (5 тем: `config`, `wallpaper`, темы rofi-launcher) | `@import` в конце темы | при следующем открытии |
| kitty | `include` в kitty.conf + SIGUSR1 | сразу |
| GTK-программы | блок `@define-color` между метками в gtk.css | после перезапуска программы |
| Экран блокировки | `source =` сразу после colors.conf в hyprlock.conf; палитра по обоям блокировки | при следующей блокировке |

Не перекрашиваются: Obsidian, Firefox, Telegram, SDDM, веб-интерфейсы проектов,
тема rofi у backup-manager (`/opt/backup-manager/ui/monochrome-vivid.rasi`).

**Серые обои.** matugen у картинки без цвета отдаёт свой встроенный голубой. Такие
обои (primary ровно `#adc6ff` и средняя насыщенность ниже 0,03) получают
монохромную схему — и интерфейс, и панель.

**Блокировка.** Цвета экрана блокировки считаются по его собственным обоям и
пересчитываются до запуска hyprlock — блокировка при включённом режиме
открывается примерно на секунду позже.

**Безопасность.** Права файлов сохраняются (в config.json панели лежит ключ погоды,
права 600). Путь к обоям с `"`, `$`, `` ` `` или `\` в панель не передаётся: она
подставляет его в команду оболочки.

## Установка и удаление

```bash
./install.sh      # копии конфигов, программа, подключение, пункт меню; режим — off
./uninstall.sh    # выключить, отключить, удалить
```

**После переустановки rofi-launcher, hyprland-dotfiles или hypr-lock-theme** их
установщики перезаписывают конфиги и скрипты обоев, и подключения пропадают —
снова выполнить `./install.sh` (повторный запуск безопасен, `wallpaper-theme status`
покажет, что не подключено).

**Переезд Hyprland на Lua-конфиг.** В `hyprland.lua.ready` цвета рамок заданы прямо,
а подключения нет: рамки будут краситься только до перезагрузки конфига, хотя
`status` скажет «подключено» (он проверяет `hyprland.conf`).
